Turn a video of a room into a 3D world you can use
University of Salford · DreamLab AI
Headline stack: COLMAP → LichtFeld Studio (3D Gaussian Splatting) → SAM 3 → TRELLIS.2 / Hunyuan3D-2.1 → NVIDIA ArtiFixer → Unreal Engine 5.8 (Nanite + NanoGS). Driven by an in-container Claude Code agent + DiffusionGemma reasoner. ~30 named SOTA components, picked per video — not one fixed recipe.

Save real places

  • Keep it forever in 3D
  • For history, games and VR
Capture: smartphone 4K (reference run used a Pixel 9 Pro); recommend 4K/60, 1/500s shutter. Routed variants: iPhone LiDAR / ARKit, event cameras. Ingest: rclone (Drive/cloud), PyAV + ffmpeg, SHA-256 integrity manifest, multi-sweep unified COLMAP. Partners: DreamLab AI · University of Salford (heritage / immersive MR).

Why it is hard

  • Phone video is shaky and blurry
  • A 3D model must be clean
  • Going from one to the other is the hard part
Quality stack: MUSIQ (via pyiqa) no-reference image quality; Q-Align (alt); Variance-of-Laplacian (full-res 4K sharpness); structure-tensor λ₂ directional motion-blur metric → automatic recapture flag. The honest finding: the limit is motion blur in the capture, not the algorithms.

What you get

  • A full 3D room
  • Each object on its own
  • Ready for a game engine
Delivery formats: FBX (baked-texture, Nanite) = the UE deliverable; GLB (PBR object intermediate); .ksplat for web (via @playcanvas/splat-transform); SOG / SPZ / compressed-PLY / PLY; USD/USDA archival only (LichtFeld's native ParticleField prim was dropped for UE). Targets: Unreal Engine 5.8, web viewers (SuperSplat / PlayCanvas).

Smart by design

  • First, check the video
  • Then pick the best way
  • Every video is different
Diagnose: MUSIQ + Variance-of-Laplacian + structure-tensor λ₂ + SfM success + coverage / under-observed % + hardware profile. Router axes: sharpness · coverage · hardware · deliverable → selects the component combo (docs/asset-creation-decision-tree.md). Step by step

  • Video → points of light
  • Points → 3D shapes
  • Shapes → real textures
  • Into the game engine
SfM: COLMAP 4.1 + ALIKED + LightGlue (SIFT is the live fallback); alts VGGT, DUSt3R, InstantSplat. 3DGS: LichtFeld Studio v0.5.3 — ImprovedGS+ with MRNF densification + PPISP; alts gsplat, 3DGUT/3DGRUT. Segmentation: SAM 3 (+ SAM 3.1 Object Multiplex), SAM 2; depth-aware mask projection. Objects (image→3D): TRELLIS.2-4B (primary) / Hunyuan3D-2.1 (fallback) / SAM-3D-Objects; view completion FLUX.2-dev (+ Mistral-3), Qwen-Image-Edit, MV-Adapter; DINOv3 conditioning; served on ComfyUI. Scene mesh: CoMe / gsplat-TSDF (Open3D) / MILo / 2DGS / PGSR / SuGaR. Cleanup+texture: MeshCleaner → xatlas → Blender Cycles bake. Engine: Unreal Engine 5.8 + Nanite + NanoGS.

Proof it works

  • 38% sharper images
  • Best with 4K video
  • Many objects, quickly
INPUT: 1× 4K/30 handheld walkthrough (Pixel 9 Pro), multi-pass; ~13,600 frames → ~1,650 kept (original run 1,200 → 600); RGB only. Footage MUSIQ ≈ 31 (below ~19 = abandon); 0% under-observed, ~90 cameras per point; blur-aware selection lifts bottom-quartile sharpness +20–38%. OUTPUT: SfM 600/600 registered (locked 750), ~290k–367k sparse points, ~1.0–1.16 px reproj; 3DGS 30,000 iterations → ~4.0M Gaussians → SuperSplat-clean 2.48M → pruned 1.55M for UE; SAM 3 found 8 objects → 3–4 reconstructed cleanly (TRELLIS.2 beat Hunyuan3D) at 4096px PBR, placed at real scale (chair 60cm, ladder 210cm); room TSDF cleaned to ~51k verts / 81k faces, 2048² albedo (planarity 72% CoMe vs 70% 2DGS — capture-limited, shipped as the NanoGS splat hero). Compute: RTX 6000 Ada 48GB; 3DGS ~25 min, CoMe ~59 min, ArtiFixer 14B peak 45.5GB. The clean win is the OBJECTS; the room is capture-limited → recapture (4K/60) is the lever.
