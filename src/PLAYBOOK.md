# Vitrine — Visual Deck Design Playbook (v1)

**Audience:** non-technical, non-native-English. → Visual-first. Minimal text. Universal icons,
numbers, arrows. One idea per slide. Inspiring, premium, optimistic.

**Goal:** 10 high-impact slides, each a single full-bleed 2K nano-banana infographic. Cohesive art
direction so the deck reads as one world.

## Design system (the "momentum" tokens — identical across all 10)
- **Mood:** wonder + confidence; "preserve real places as living 3D worlds."
- **Palette:** dark midnight navy→teal gradient background; luminous **cyan** + **electric blue**
  accents; **warm amber** for the human/heritage warmth; clean white.
- **Illustration:** soft-3D isometric, clean vector clarity, glowing edges, **points-of-light /
  particle-cloud motif** (nods to Gaussian splats), cinematic top-left key light, gentle depth/bokeh.
- **Layout:** one centered focal metaphor, generous negative space, uncluttered, keynote-grade.
- **Text:** avoid it; only a few exact short words when essential; never gibberish.
- **Recurring cast:** the glowing "room twin", separable 3D object-cubes, the friendly AI agent in a
  glass container, the game-engine portal, light-particle streams.

## The 10-slide story (condensed, low-tech)
1. **Title** — video of a room → a glowing 3D world. ("VITRINE")
2. **Context** — preserve real/heritage places forever as 3D.
3. **The challenge** — ordinary video is messy; good 3D is hard.
4. **What you get** — a room + reusable object assets, ready in a game engine.
5. **The approach** — check the video, then choose the best path (capture-adaptive).
6. **The pipeline** — a simple icon chain: video → points → shape → textured objects → engine.
7. **The harnessed AI agent** — an autonomous agent in a container runs the whole factory.
8. **Stats / impact** — a few big, celebratory numbers & gauges.
9. **Options** — a flexible toolbox; pick the right tool.
10. **Result + vision** — the finished world, explored in MR; the future.
